# Mobile app (apps/mobile)

The iOS/Android app: Expo SDK 58, React Native 0.88, React 19, Expo Router (typed routes), TypeScript. Moved from the repo root to `apps/mobile` on 2026-11-12 without changing its code, UI or behaviour (every file under `src/`, `assets/`, `app.json`, `tsconfig.json`, `eslint.config.js`, `package-lock.json` is byte-identical to before; only `package.json` lost the `web` script and the two DB scripts, which moved to the repo root).

The production web is the Angular app in `apps/web`. The mobile code still has its wide-screen layout and depends on `react-native-web` (Expo DOM components need it for the rich-text editor), but it is no longer built or deployed for the web.

## Commands (from apps/mobile)

```bash
npm install
# apps/mobile/.env.local: EXPO_PUBLIC_SUPABASE_URL, EXPO_PUBLIC_SUPABASE_KEY (see apps/mobile/.env.example)
npx expo start               # dev server; the phone runs a development build (Expo Go cannot do Google sign-in)
npm run android              # expo run:android
npm run ios
npm run lint
npm run typecheck
npm test                     # node src/lib/logic.check.ts
```

From the repo root: `npm run mobile`, `npm run mobile:android`, `npm run mobile:check`.

Android debug APK without a device: `cd apps/mobile/android && ./gradlew assembleDebug -PreactNativeArchitectures=arm64-v8a`, then `adb install -r app/build/outputs/apk/debug/app-debug.apk`.

## After the move

- `android/` is generated by Continuous Native Generation and gitignored (now `apps/mobile/android/`). Its CMake caches (`android/app/.cxx`) held absolute paths to the old `node_modules`; they were cleared. If a native build complains about paths, clear `android/app/.cxx` again or run `npx expo prebuild -p android --clean`.
- `.env.local` for the app is now `apps/mobile/.env.local` and holds only the `EXPO_PUBLIC_*` keys; the DB password stays in the root `.env.local`.
- `src/lib` keeps this app's copy of the shared rules; `packages/core` has the same rules for the web. Change a rule in both until the mobile app is pointed at `packages/core` (see docs/architecture/overview.md, "Sharing").
- Expo-specific rules for agents: `apps/mobile/AGENTS.md`.
